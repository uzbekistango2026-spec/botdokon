# BotDo'kon

Telegram botlar uchun restoran va do'kon Mini App tizimi (Cloudflare Worker).

- `worker.js` — butun tizim (admin panel, Mini App, Telegram webhook) bitta faylda
- `zuwoo-menyu.json` — Zuwoo (Chust Burger) menyusi, admin paneldagi «Menyuni fayldan yuklash» orqali yuklanadi

Admin panel: `/admin` · Versiya tekshiruvi: `/version`
